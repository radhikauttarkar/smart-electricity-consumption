# Smart Electricity Consumption & Optimisation

## 📌 Project Overview
Smart Electricity Consumption & Optimisation is a Machine Learning project designed to analyse household electricity usage, predict consumption, classify consumption levels, and provide energy-saving suggestions.

The application is built using Python and Streamlit, with interactive dashboards to help users understand and optimise electricity consumption.

## 🎯 Objectives
- Predict household electricity consumption using Machine Learning.
- Classify consumption into LOW and HIGH levels.
- Analyse electricity usage through visualisations and reports.
- Provide energy optimisation suggestions.
- Explore consumption scenarios and goals.

## 🛠️ Technologies Used
- **Python** – Core programming language
- **Pandas & NumPy** – Data processing and numerical operations
- **Scikit-learn** – Machine Learning models and evaluation
- **Matplotlib & Seaborn** – Data visualisation
- **Streamlit** – Interactive web application
- **ReportLab** – PDF report generation, if enabled in the application

## 🤖 Machine Learning
The project includes electricity consumption prediction and consumption-level classification.

Model performance is evaluated using metrics such as:
- **MAE** – Mean Absolute Error
- **RMSE** – Root Mean Squared Error
- **R² Score** – Measures how well the regression model explains variation in consumption

The application also provides model performance comparisons and consumption insights.

## 📊 Features
- Electricity consumption prediction
- LOW/HIGH consumption classification
- Energy optimisation suggestions
- Insights and reports
- Forecasting and what-if scenarios
- Consumption goals
- Model performance evaluation
- PDF and CSV report options, where supported

## 📁 Dataset
The project uses `Smart_Household_Electricity_Consumption_Dataset.csv` for household electricity consumption analysis and model development.
